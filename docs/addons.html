TOOLING / 01

Reusable code, locally.

Put reusable R+ functions in a .rpa addon. Imports are local file reads, so code does not silently download and execute remote programs.

Create an addon

// math.rpa
fn twice(value: Int) -> Int {
    return value + value
}

Import and call it

// main.rp
import math.rpa

println(math.twice(21))

The filename becomes the namespace. These paths are supported relative to the importing file:

import math.rpa
import utils/math.rpa
import ../shared/math.rpa

Addon chains

An addon can import another addon using the same syntax. R+ resolves the chain locally and compiles the resulting program together.

SAFETY NOTE

Remote HTTP imports are intentionally not supported. Download code yourself, inspect it, and keep it in your project before importing it.
