LANGUAGE / 01

The basics.

R+ keeps everyday code short and readable, while still making types and mutation explicit.

Values and variables

let title = "R+"
let count: Int = 3
let ready: Bool = true
mut score = 0
score = score + 10

let creates an immutable binding. Use mut when the binding itself needs to change.

Types

Int

Whole numbers

42

Float

Decimal numbers

3.14

Bool

True or false

true, false

String

Text

"hello"

Operators

+  -  *  /       arithmetic
==  !=  <  <=  >  >= comparisons
&&  ||  !         boolean logic

&& and || short-circuit, so the right side only runs when needed.

Built-ins

println(value), print(value), input(prompt), randomize(text), and len(value) are available by default.
