LANGUAGE / 02

Make code move.

Use conditions for choices and loops for repetition. Braces mark every block.

Conditions

if score > 10 {
    println("high score")
} else {
    println("keep going")
}

While loops

mut count = 0
while count < 3 {
    println(count)
    count = count + 1
}

For loops

for item in [1, 2, 3] {
    println(item)
}

Use break to leave the nearest loop and continue to skip to its next iteration. Both are rejected outside loops.
