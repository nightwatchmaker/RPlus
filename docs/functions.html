LANGUAGE / 03

Functions, no fuss.

Declare a function with fn. Parameters and return types can be explicit when you want stronger checks.

Declare and call

fn add(a: Int, b: Int) -> Int {
    return a + b
}

println(add(20, 22))

Unit functions

A function without a useful result can return Unit:

fn greet(name: String) -> Unit {
    println("hi " + name)
}

Functions can call other functions, use control flow, and work with structs and lists.
