Getting started.

R+ runs directly from the repository with Python. You can interpret a file while learning, then compile it to a native executable when you want.

Run a program

python3 -m rplus examples/hello.rp

The command reads a .rp source file, checks its types and ownership rules, then runs it with the interpreter.

Your first file

let name = "R+"
println("hello, " + name)

Useful CLI commands

--native

Compile to C

python3 -m rplus --native ./hello examples/hello.rp

--eval

Run a quick snippet

python3 -m rplus --eval 'println(1 + 2)'

What happens next?

R+ checks your program in stages: parsing, type checking, ownership checking, and execution. If you are new, read Language basics next.
