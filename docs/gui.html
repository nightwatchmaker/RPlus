TOOLING / 02

Make things move.

R+ has a small interpreter-mode GUI module, inspired by beginner-friendly libraries like pygame. It uses Tkinter, so Python needs Tk support installed.

Open a window

gui.open("R+ demo", 640, 480)

while !gui.should_close() {
    gui.clear(24, 32, 38)
    gui.rectangle(80, 80, 120, 90, 200, 80, 90)
    gui.present()
}

Available operations

gui.open

Create a window

Title, width, and height.

gui.clear

Clear the canvas

RGB background color.

gui.rectangle

Draw a shape

X, Y, width, height, then RGB.

gui.present

Update the screen

Process window events and redraw.

gui.key_down

Read keyboard state

Pass a key name such as space.

gui.close

Close the window

Ends the GUI session.

CURRENT LIMIT

GUI support currently runs through the interpreter only. --native rejects GUI programs explicitly instead of producing a broken executable.
