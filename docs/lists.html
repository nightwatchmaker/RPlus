LANGUAGE / 05

Lists that stay simple.

Lists hold values of one type. Indexing starts at zero, and len works for lists and strings.

Create and read

let values = [10, 20, 30]
println(values[0])
println(len(values))

Mutate a list

mut values = [10, 20, 30]
values[1] = 99
println(values[1])

Index assignment requires a mutable binding. Indexes must be Int values, and out-of-bounds access is rejected at runtime.

Iterate

for value in values {
    println(value)
}
