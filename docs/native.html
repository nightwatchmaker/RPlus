TOOLING / 02

Ship it native.

The native backend lowers checked R+ code to C, then uses Clang to produce an executable.

Compile a file

python3 -m rplus --native ./hello examples/hello.rp
./hello

The output path comes immediately after --native. Native compilation supports functions, structs, methods, lists, loops, indexing, addons, and the built-ins documented here.

What gets checked first?

01

Parse

Turns source text into an AST.

02

Type check

Validates values, calls, fields, and operators.

03

Ownership check

Validates moves, borrows, and mutation.

Native requirements

You need clang available on your PATH. If you are learning the language, the interpreter path has no compiler dependency.
