Mutation with guardrails.

R+ checks ownership and borrowing before execution so accidental use-after-move patterns are caught early.

Copy values

let a: Int = 10
let b = a
println(a + b)

Primitive values such as Int, Float, Bool, and Unit are copy-friendly.

Mutable bindings

mut point = Point { x: 0, y: 0 }
point.x = 5

Struct field mutation requires a mutable binding, or a method receiver declared as &mut self. Immutable bindings cannot be changed behind the checker's back.

Borrowing

Use &Type for a shared reference and &mut Type for a mutable reference. The same rules apply to methods and regular function parameters.
