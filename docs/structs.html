LANGUAGE / 04

Shape your data.

Structs group named fields. An impl block attaches methods to a struct.

Define a struct

struct Point {
    x: Int
    y: Int
}

let origin = Point { x: 0, y: 0 }
println(origin.x)

Attach methods

impl Point {
    fn sum(self: &Point) -> Int {
        return self.x + self.y
    }
}

println(origin.sum())

Use &mut self when a method mutates the receiver. The ownership checker makes sure that mutation is allowed.
